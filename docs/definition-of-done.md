# Definition of Done — MercaSport

Une tâche peut passer en Done lorsque tous les critères
applicables ci-dessous sont validés.

## Fonctionnement et qualité
- [ ] La fonctionnalité fonctionne localement.
- [ ] Le scénario de test manuel a été rejoué avec succès.
- [ ] Les erreurs principales sont gérées.
- [ ] Les contrôles de rôle et de propriété sont respectés, si nécessaire.
- [ ] Le code a été relu par un autre membre.
- [ ] La PR contient une seule tâche, est liée à l'Issue et est fusionnable.
- [ ] La documentation est mise à jour si l'installation ou le contrat API change.
- [ ] Aucun secret n'est versionné.

## Learning Check
- [ ] L'auteur peut expliquer pourquoi cette tâche existe.
- [ ] L'auteur peut expliquer le chemin des données.
- [ ] L'auteur peut expliquer une erreur possible et sa gestion.
- [ ] L'auteur peut expliquer les lignes importantes de son code.
- [ ] L'auteur peut expliquer comment il a testé.
- [ ] Le reviewer peut reformuler la solution.

Un critère non applicable doit être justifié dans la PR.
Une tâche qui fonctionne mais reste incomprise ne passe pas en Done.
