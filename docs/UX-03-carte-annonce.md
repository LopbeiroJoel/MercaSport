# UX-03 — Données d’une carte d’annonce

Responsable : Joel. Reviewer : Matteo. Sprint : S1.

## Informations affichées

| Information | Champ envisagé | Provenance envisagée |
|---|---|---|
| Titre de l’annonce | title | Annonce |
| Nom du club | name | Club lié à l’annonce |
| Poste recherché | name | Poste lié à l’annonce |
| Description courte | description, raccourcie à l’affichage | Annonce |

## Interactions

- L’identifiant de l’annonce permet de charger son détail et de postuler.
- Les boutons « Voir les détails » et « Postuler » sont des éléments d’interface.
- Seules les annonces approuvées apparaissent dans la liste publique.

## Validation à effectuer

Les noms de champs sont provisoires et doivent être confirmés avec le schéma SQL et le contrat API.
